# Web Engineering JS / Frontend Coursework

Repozytorium rozwiązań zadań i projektów laboratoryjnych z zakresu inżynierii webowej (Angular & React).

## Struktura katalogów

```
JS/
├── JavaScript/            # Zadania wprowadzające: Vanilla JavaScript & DOM
│   └── zadanie-1/         # Typowanie, tablice, obiekty, manipulacja DOM
├── Angular/               # Workspace Angular 22 (Multi-Project)
│   ├── projects/
│   │   └── zadanie-2/     # Drugie zadanie pracowni specjalistycznej
│   ├── angular.json
│   └── package.json
└── React/                 # Środowisko React 19 + Vite (kolejne zadania)
    └── README.md
```

## Standardy technologiczne

- **Runtime:** Node.js 26+ / 24+
- **Angular:** v22+ (Standalone Components, Signals, Zoneless Change Detection, New Control Flow)
- **React:** v19+ (Vite, TypeScript, Tailwind CSS)
- **CSS:** Tailwind CSS v4, SCSS
- **Testing:** Vitest
