# Zadanie 3 – Angular (Komponenty, Szablony, Sygnały)

Sprawozdanie z realizacji zadań z trzeciej listy pracowni specjalistycznej Angular.

---

## Jak uruchomić projekt

W katalogu `Angular/`:

```powershell
# Uruchomienie serwera deweloperskiego dla zadania 3
npm run start:zadanie-3

# Uruchomienie testów jednostkowych
npm run test:zadanie-3

# Zbudowanie projektu
npm run build:zadanie-3
```

Aplikacja będzie dostępna pod adresem: [http://localhost:4200/](http://localhost:4200/).
